# Ripple glossary

One name per thing. Buttons, menus, titles, tooltips, and errors use these words.

| Term | Means | Not |
| --- | --- | --- |
| Disc | The physical CD in the drive | CD (in the UI), media, volume |
| Track | One song on a disc or in the burn list | song, file, item |
| Album | The title, artist, year, and cover that belong to a disc | release (except in the match picker), record |
| Rip | Copy a disc's tracks to files on the Mac | import, extract, convert, grab |
| Burn | Write tracks onto a blank disc | record, write |
| Audio CD | A burned disc in the standard audio CD format: it plays in old CD players, car stereos, and boom boxes (MP3 and M4A files converted to CD audio) | Audio Disc, music CD, Red Book |
| MP3 Disc | A burned disc holding MP3 files, in folders if you like; M4A files are converted to MP3 | data CD, MP3 CD |
| Mode | Rip or Burn: what the window is for | tab, page |
| Installer | The downloaded Ripple.dmg, the disk image you drag Ripple out of | setup, package |
| Source Folder | The Mac folder whose MP3 and M4A files get burned | input folder, library |
| Format | MP3 or M4A, the kind of file a rip makes | codec, encoder, type |
| Quality | How much detail an MP3 keeps: variable (default) or a fixed rate | bitrate, preset |
| Output Folder | Where ripped albums are saved | destination, library |
| Match | An album the lookup found for a disc | result, release (in the picker the row says release details) |
| Disc Folder | A folder made on an MP3 Disc to hold files | directory, playlist |
| Cover | The album's picture | art, artwork, image |
| Check for Errors | Read each part of the disc until two reads agree | verify, secure mode |
| Retry | Rip one track again, replacing its file | Re-rip, Redo |
| Needs Attention | A track that may have errors after ripping | failed, bad, corrupt |
| Show in Finder | Reveal the finished album folder | Open folder, Reveal |
| Eject | Push the disc out of the drive | Remove, Unmount |
| Cancel | Stop a rip or a burn before it finishes | Abort, Stop |
| BradysBit | The brand that makes Ripple. Shown in the About window and the copyright line, not in the window title | publisher, company |
| Video DVD | A burned disc in the standard DVD-Video format with a menu: it plays in any DVD player | movie disc, DVD movie, data DVD |
| Title (on a Video DVD) | One video on the disc, with a button in the menu | movie, clip, file |
| Menu | The screen a Video DVD opens on, with a button for each title | home screen, index |
| Chapter | A point inside a title that the player's Next button jumps to | scene, marker |
| TV Standard | NTSC (US) or PAL (Europe): how many lines and frames a second the disc is made for | region, format |
| Disc Image | A single .iso file that holds a whole Video DVD, for later burning or for a DVD player app | ISO, backup |
